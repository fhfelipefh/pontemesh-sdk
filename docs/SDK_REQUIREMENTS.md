# Requisitos do SDK

- RF-SDK01 consultar Origin
- RF-SDK02 obter access package
- RF-SDK03 interpretar manifesto
- RF-SDK04 selecionar fontes autorizadas
- RF-SDK05 baixar fragmentos por Range
- RF-SDK06 validar sha256
- RF-SDK07 preservar progresso
- RF-SDK08 fallback para Origin
- RF-SDK09 usar Replica/Edge quando autorizada
- RF-SDK10 modelar PEER como fonte autorizada
- RF-SDK11 suportar adapter P2P plugável
- RF-SDK12 reportar eventos de fragmento quando possível
- RF-SDK13 expor API pública simples
- RF-SDK14 não usar API admin/MCP/banco
